# ESP32 Quadcopter

ESP32 Quadcopter is an ESP-IDF-based flight-control project focused on building a modular quadcopter firmware stack. The current stage is MPU6050 sensor bring-up and driver development, with future work planned for attitude estimation and PID control.

## Current Status
- MPU6050 driver component in progress
- Main application used for sensor testing
- README and project structure are being finalized

## Future Work
- Calibration
- Attitude estimation
- PID control
- Motor control integration

## Components
- `components/mpu6050/` — MPU6050 driver component
